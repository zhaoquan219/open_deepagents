# Release 1.0.0

## Summary

This release promotes the verified `new` branch into the main release line and marks the project as the first stable `1.0.0` baseline.

## Highlights

- Removes bearer tokens from browser-visible upload download URLs.
- Downloads attachments with `Authorization` headers instead of query-string credentials.
- Replaces Markdown denylist cleanup with allowlist sanitization.
- Wires the frontend stop action to backend run cancellation.
- Stops runtime event persistence after cancellation or session archive.
- Makes checkpoint probe failures explicit instead of treating them as missing checkpoints.
- Makes session delete/archive hide normal history/run/upload access and revoke uploads.
- Changes `/ready` into a read-only product-schema and runtime-persistence probe.
- Adds regression coverage for auth, uploads, archive/delete, cancellation, readiness, checkpoint failures, event persistence, process logs, clipboard, stores, and bootstrap behavior.
